## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/hardik-m-yadav/hardik-portfolio.git
```

Navigate into the project:

```bash
cd hardik-portfolio
```

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```
